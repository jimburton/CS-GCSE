# Relational database exercises

Run the script `load_data.py` to create the School Clubs database and
load some sample data.

The script creates a database, `school_clubs.py`, in the same
directory as the Python script. Upload the database to
[https://tablesviewer.com/sqlite-viewer/](https://tablesviewer.com/sqlite-viewer/) to explore the data and
complete the following exercises.

## Exercises

For each exercise, work on the SQL query in the online viewer. **When
you get it working keep a record of the query before moving on to the
next exercise**. E.g. copy the query into a text file.

1. List the names of all students in alphabetical order.
2. Find the id and name of the club named 'Coding Club'.
3. Find the name and capacity of all rooms that can hold more than 25
   people.
4. Display a list of all club names and the rooms they meet in.
5. List every club name alongside the name of the student who leads
   that club.
6. List the names of all students who are members of the Art Club.
7. Insert a new student called 'Miles Morales' and make them into a
   member of the Coding Club.
8. The Drama Club is moving to Room 402. Update the clubs table to
   reflect this.
9. Alice Smith (id: 1) has graduated -- remove her student
   record. Note that you must remove her memberships before you can do
   this. **Why is that?**
10. Complete the functions in `school_clubs.py` using the queries you
    wrote for the previous exercises.
